JOKJUNG Back Office V3.30 — Navigation System

Mobile navigation standard:
1) หน้าหลัก -> Dashboard
2) การเงิน -> Financial Summary
3) Stock -> วัตถุดิบ / Stock
4) จัดซื้อ -> Purchase Orders
5) เพิ่มเติม -> Daily Closing, EOD, Sales History, Reconciliation, P&L, Expenses, Stock Count, Movement, Reports, Cost Control, Supplier, Purchase Docs, Returns, Employees

Also standardized:
- Tab groups use segmented-control style where applicable.
- Quick range controls (วันนี้ / 7 วัน / เดือนนี้) use the same visual component.
- Dark mode and Light mode are both supported.

Main UI CSS:
- css/jokjung-ui-v3.30.css

Navigation JS:
- js/jokjung-nav-v3.30.js

This update changes UI/navigation only. It does not modify SQL, Supabase, EOD, Stock calculations, or business logic.
